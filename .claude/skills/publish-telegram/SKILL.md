# Публикация в @auto_generals — один маршрут

Любой пост в канал идёт по одной цепочке, шаги не пропускаются:

данные → цена по единой формуле → единый шаблон → проверка дублей → черновик → «да» владельца → публикация → запись в реестр.

## Как вызывать
- Лот по ссылке HeyDealer: `python publish_lot.py <ссылка> --bid … --title … --hp …` — по умолчанию **dry-run** (только черновик). Публикация — только с `--publish`, и только после «да» владельца в чате (`--yes` ставить лишь тогда).
- Проверка отправки — `--chat <тестовый чат>`: текст получает `[ТЕСТ] `, в реестр не пишется.
- Автоматические лоты — `main_pipeline.py` (по расписанию GitHub Actions) через `agent_publisher.publish_post()`.
- Вход в HeyDealer только с явным `--login`.

## Режимы шаблона (`post_render.render_post(lot, mode)`)
- **auction** — торги. Публикуется **всегда с подтверждением** владельца, автоматика его не использует.
- **lead** — бронирование. Может идти автоматикой, но только лоты, прошедшие гейт и проверку дублей.

## Запрещено
- Публиковать в обход этого маршрута (прямая отправка в Telegram, `curl`, свои скрипты).
- Менять формулу цены или шаблон в обход конфигурации: цена — `pricing.py` + параметры в `config.py`; текст — `post_render.py` + `post_format_schema.py` + тесты.
- Показывать токены и пароли (называть можно только имена переменных); открывать `.env`.
- Пушить и сливать в `main` без «да» владельца.
- Обходить проверки (`ValidatedCar`, гейт `validate_post_before_publish()`, дубли).

## Где что лежит
- Формула цены: `pricing.calculate_price()`; параметры — `config.py` (`KOREA_COSTS_PCT` 14 %, `BANK_COMMISSION_PCT` 0,5 %, `LOGISTICS_RUB`, `BROKER_FEE_RUB`, `MARGIN_RUB`, `IMPORTER_TYPE`, необязательный `KRW_PER_RUB`). Значения из `.env` и секретов GitHub перекрывают default.
- Таможенные ставки и утильсбор: `customs_rates.py`.
- Шаблоны: `post_render.py` (режимы auction/lead), проверка формата — `post_format_schema.py`.
- Реестр опубликованного: `published.jsonl` (`registry.py`). Создан в ветке **work/registry** — в `main` его нет, пока ветка не слита; источник правды — сам канал (`python registry.py reconcile`).
- Дубли: `registry.find_duplicate()` (lot_id/URL, затем модель + год + пробег ±50 км); `DuplicatePostError` — штатный пропуск.

## Контрольный лот для цены
Kia Ray Signature (998 см³, 76 л.с.), режим фиксированного курса `KRW_PER_RUB = 15,2`, комиссия банка 0,5 %:
- ставка 12 млн ₩ → **1 518 112 ₽**
- ставка 13 млн ₩ → **1 584 230 ₽**

Расхождение — повод остановиться и сверить параметры (`config.py`, `.env`, секреты GitHub), а не подгонять формулу. Проверка: `python test_price_formula.py`.

## Утильсбор
Льготные **5 200 ₽** — только для ввоза на себя (физлицо) и двигателя **до 160 л.с.** (и до 3000 см³). Иначе — коммерческий утильсбор, формула возвращает предупреждение. В тексте поста слово «утильсбор» не пишется.
