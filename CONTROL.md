# CONTROL.md — как управлять публикацией (простыми словами)

Три простых действия, каждое — одна строка текста или одна команда в
терминале. Ничего в JSON/YAML руками редактировать не нужно.

1. **Добавить модель** — дописать строку в `models_to_watch.txt`.
2. **Опубликовать прямо сейчас** — `python publish_now.py "Марка Модель"`.
3. **Приостановить/включить автопубликацию** — `python control.py pause` /
   `python control.py resume`.

Дальше — подробно про каждое, и в конце — живой пример на Kia K5: от
строки в списке до готового поста.

---

## 1. Как добавить модель, которую надо искать и публиковать

Открой файл **`models_to_watch.txt`** (обычный текстовый файл в папке
проекта) и допиши новую строку — марка и модель через пробел, без кавычек
и скобок:

```
Kia K5
Hyundai Tucson
```

Всё. Сохранил файл — готово.

**Когда это сработает:** при следующем автоматическом запуске поиска (он
идёт сам каждые 6 часов) программа сама заметит новую строку и начнёт
искать эту модель на площадках, откуда берутся объявления. Строку можно
дописать в любой момент, редактировать код или другие файлы не нужно.

Если не хочется ждать до 6 часов — см. пункт 2, можно опубликовать сразу.

Пустые строки и строки, начинающиеся с `#`, игнорируются — можно оставлять
себе заметки, например:
```
# добавил 06.07, ждём результата
Kia K5
```

**Важно:** это только ДОБАВЛЯЕТ модели в поиск. Если модель разонравилась
и её нужно убрать — удали строку из `models_to_watch.txt`, но этого
недостаточно (сам список моделей для поиска — отдельный файл
`target_models.json`, куда эта строка уже перенесена и откуда её надо
убрать отдельно) — просто попроси меня убрать модель из поиска, я сделаю
это за минуту.

**Про новые, ранее не публиковавшиеся модели:** иногда для совсем новой
модели ещё нет записи о характеристиках двигателя (см. пункт 2) — тогда
программа честно скажет об этом, а не опубликует пост с придуманной
ценой. В этом случае просто напиши мне — я проверю и добавлю точные
данные (разовая правка, обычно занимает несколько минут).

## 2. Как опубликовать конкретное авто прямо сейчас

Одна команда в терминале, из папки проекта:

```
python publish_now.py "Kia K5"
```

Программа сама:
1. Поищет подходящие объявления этой модели прямо сейчас (не дожидаясь
   расписания).
2. Отбросит непрямые предложения (например, переуступку договора
   аренды) — публикуются только обычные предложения о продаже.
3. Выберет из подходящих самое привлекательное (например, с меньшим
   пробегом).
4. Соберёт пост в ТОМ ЖЕ виде, в каком выходят обычные посты в канал.
5. Опубликует его.

**Перед тем как публиковать по-настоящему, можно сначала посмотреть, что
получится**, ничего не отправляя, добавив `--dry-run`:

```
python publish_now.py "Kia K5" --dry-run
```

Программа покажет готовый текст поста прямо в терминале — можно проверить
цену, характеристики, фото — и только потом решить, публиковать ли без
`--dry-run`.

Если для этой модели ничего подходящего не нашлось — программа так и
скажет ("не нашёл подходящих объявлений"). Если объявления нашлись, но
для них не хватает данных о двигателе — программа тоже скажет об этом
прямо (см. примечание в пункте 1).

Публикация одной и той же машины дважды исключена — если она уже выходила
в канал (по расписанию или вручную), программа откажется публиковать её
снова (если это осознанно нужно — есть флаг `--force`).

## 3. Как приостановить/возобновить автопубликацию

```
python control.py status    — посмотреть текущее состояние
python control.py pause     — приостановить автопубликацию по расписанию
python control.py resume    — включить обратно
```

`pause`/`resume` сразу отправляют изменение туда, где реально крутится
расписание (GitHub) — после команды ничего больше делать не нужно,
расписание остановится/возобновится в течение нескольких минут.

Ручная публикация (пункт 2) на паузу не влияет — `publish_now.py` работает
всегда, независимо от того, включено расписание или нет.

**Проверки честности цены одинаковы везде.** И расписание, и
`publish_now.py`, и пауза/возобновление используют один и тот же код
поиска и расчёта цены — нет отдельной, "облегчённой" версии для ручного
запуска. Если позже найдётся ещё одна проблема вроде переуступки аренды
или стартовой цены аукциона — исправление в одном месте автоматически
подействует на все три способа публикации.

## Живой пример: Kia K5, от строки в списке до готового поста

1. **Добавили строку** в `models_to_watch.txt`:
   ```
   Kia K5
   ```

2. **Опубликовали прямо сейчас** (пока в тестовом режиме, чтобы сверить
   цифры перед реальной публикацией):
   ```
   python publish_now.py "Kia K5" --dry-run
   ```

3. **Программа сама нашла и показала пост:**
   ```
   Kia K5 2.0 — уже можно забронировать!

   Характеристики:
   Год: 2026
   Двигатель: 2.0 л, 160 л.с.
   КПП: не указано
   Пробег: 7 км

   Стоимость под ключ в Казани: 4 141 243 ₽

   Пишите мне — посчитаю точный расчёт под ваш бюджет: @korea_auto_kazan_bot
   ```
   (найдено 4 фото — в реальной публикации пост уходит в канал альбомом с
   этими фото и этим же текстом подписью)

4. Цифры и текст устраивают — убираем `--dry-run` и запускаем ту же
   команду ещё раз, пост уходит по-настоящему в @auto_generals.

С этого момента Kia K5 также в общем списке моделей — при следующих
плановых запусках (каждые 6 часов) программа продолжит сама искать новые
объявления этой модели, без каких-либо дополнительных действий с твоей
стороны.

## Что уже проверено и подправлено при подготовке этой инструкции

Пока готовил живой пример, всплыли две реальные проблемы с данными — обе
разобраны и исправлены (или сознательно отложены):

- **Одна из площадок (Encar) иногда публикует переуступку договора
  аренды** под тем же полем "цена", что и обычную продажу — сумма там в
  разы меньше рыночной стоимости машины, из-за чего расчёт "под ключ"
  получался абсурдно заниженным. Теперь такие предложения отсеиваются
  автоматически — публикуются только обычные предложения о продаже.
- **Пробовали добавить Hyundai Sonata** — но её объявления смешивают
  обычный бензиновый и гибридный варианты под очень похожим текстом
  названия, а точных данных по гибридному двигателю нет — решили не
  рисковать неточной ценой и отложить эту модель до отдельной проверки.
- **Ещё одна площадка (OnBid, государственные аукционы)** показывает не
  окончательную цену, а стартовую цену торгов — итоговая может оказаться
  выше. Для таких объявлений в посте теперь честно написано «Стартовая
  цена аукциона... (итоговая может быть выше)» вместо обычной формулировки.

Это не значит, что для новой модели гарантированно всё пройдёт с первого
раза — но именно на такие случаи программа останавливается и честно
говорит "не хватает данных", а не публикует что попало.
