# Как настроить автоматический запуск через GitHub Actions

Это пошаговая инструкция для полного новичка в Git/GitHub — не пропускай
шаги, даже если что-то кажется очевидным.

## Зачем это вообще нужно

Сейчас бот запускается только тогда, когда ТЫ вводишь `python main.py`
на своём компьютере. GitHub Actions — это способ запускать код "в облаке",
автоматически по расписанию, даже когда твой компьютер выключен.

## Шаг 1. Создай аккаунт на GitHub (если ещё нет)

Зайди на https://github.com, зарегистрируйся (бесплатно).

## Шаг 2. Установи Git на компьютер

Если не установлен: скачай с https://git-scm.com/download/win, поставь
с настройками по умолчанию (просто нажимай "Next").

Проверь, что установился — в `cmd`:
```
git --version
```

## Шаг 3. Создай новый репозиторий на GitHub

1. На github.com нажми "+" (вверху справа) → "New repository"
2. Назови его, например, `auto-dealer-bot`
3. Выбери **Private** (важно! чтобы никто посторонний не видел твой код и
   структуру проекта, даже если секреты и так отдельно защищены)
4. НЕ ставь галочку "Add a README file" (у нас уже есть свои файлы)
5. Нажми "Create repository"

Появится страница с инструкциями — тебе понадобится строка вида
`https://github.com/твой_логин/auto-dealer-bot.git` — скопируй её.

## Шаг 4. Отправь код проекта на GitHub

Открой `cmd`, перейди в папку `auto_dealer_bot`:
```
cd C:\Users\Xiaomi\auto_dealer_bot
```

Инициализируй Git-репозиторий и отправь код (замени ссылку на свою из Шага 3):
```
git init
git add .
git commit -m "Первая версия бота"
git branch -M main
git remote add origin https://github.com/твой_логин/auto-dealer-bot.git
git push -u origin main
```

При первом `git push` Git может попросить войти в аккаунт GitHub —
следуй подсказкам на экране (обычно откроется браузер для входа).

⚠️ **Важная проверка перед этим шагом:** убедись, что у тебя есть файл
`.gitignore` (мы его создали) — он не даст файлу `.env` (с твоими
токенами) попасть в репозиторий. Если вдруг случайно закоммитил `.env` —
СРАЗУ смени токен бота у @BotFather (старый токен нужно считать
скомпрометированным).

## Шаг 5. Добавь секреты в настройки репозитория

1. На странице своего репозитория на GitHub → вкладка **Settings**
2. Слева: **Secrets and variables** → **Actions**
3. Кнопка **New repository secret** — добавь каждый из них ПО ОДНОМУ
   (имя точно как здесь, значение — своё реальное):

| Имя секрета | Значение |
|---|---|
| `BOT_TOKEN` | токен бота от @BotFather |
| `TELEGRAM_CHAT_ID` | `@auto_generals` (или твой канал) |
| `ADMIN_CHAT_ID` | твой личный chat_id для уведомлений об ошибках |
| `LOGISTICS_RUB` | сумма доставки, например `190000` |
| `BROKER_FEE_RUB` | сумма услуг брокера, например `90000` |
| `MARGIN_RUB` | твоя комиссия, например `150000` |
| `BANK_COMMISSION_PCT` | комиссия банка за перевод (доля от 0 до 1), например `0.025` (это 2.5%) |
| `IMPORTER_TYPE` | `phys` |
| `VK_TOKEN` | пользовательский (user) VK-токен с правами `photos,wall,groups` — ⚠️ ИМЕННО пользовательский, не групповой из настроек сообщества (групповой умеет постить текст, но не умеет грузить фото, см. FINAL_STATE.md раздел 9); проще всего получить через клиентское приложение Kate Mobile |
| `VK_OWNER_ID` | отрицательный ID сообщества VK, например `-239942884` |

Эти секреты нужны ОБОИМ workflow-файлам (`run_bot.yml` для `main.py` и
`main_pipeline.yml` для `main_pipeline.py`) — настраиваются один раз, общие
для всего репозитория. `VK_TOKEN`/`VK_OWNER_ID` — необязательные: если их
не завести, публикация в Telegram работает как обычно, VK просто молча
пропускается (`vk_publisher.is_configured()`).

## Шаг 6. Проверь, что всё работает

1. На странице репозитория → вкладка **Actions**
2. Слева должен появиться workflow "Auto Dealer Bot"
3. Нажми на него → справа кнопка **Run workflow** → **Run workflow**
   (это запускает бота вручную, не дожидаясь расписания)
4. Через минуту-две обнови страницу — увидишь прогон (зелёная галочка —
   успех, красный крестик — ошибка, нажми на прогон, чтобы посмотреть лог)

## Шаг 7. Дальше — само по расписанию

Как только первый ручной запуск прошёл успешно — дальше бот будет
запускаться сам, каждые 6 часов, без твоего участия. Проверять
результаты можно в Telegram-канале (посты) или на вкладке Actions
(история запусков).

## Как поменять частоту запуска

Открой `.github/workflows/run_bot.yml`, найди строку:
```yaml
- cron: "0 */6 * * *"
```
`*/6` значит "каждые 6 часов". Поменяй на `*/4` для каждых 4 часов.
Сохрани файл, и отправь изменение на GitHub:
```
git add .github/workflows/run_bot.yml
git commit -m "Меняю расписание"
git push
```

## Если что-то пошло не так

Вкладка **Actions** → кликни на неудачный прогон (красный крестик) →
там будет подробный лог с текстом ошибки — пришли мне скриншот или
текст ошибки, разберёмся.
