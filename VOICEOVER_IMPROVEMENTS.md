# Улучшения озвучки видео (TTS)

Дата: 2026-07-22

## Проблемы, которые решены

### 1. Однотипность озвучки
**Было:** Один SYSTEM_PROMPT → всегда одинаковая озвучка, монотонная подача.

**Решение:** 5 вариантов SYSTEM_PROMPT с разными зацепками/стилями:
- **Вариант 0**: Стандартный (дружелюбная подводка)
- **Вариант 1**: Энергичный тон с восклицанием
- **Вариант 2**: Вопросительный стиль (обращение к слушателю)
- **Вариант 3**: Спокойный, информационный
- **Вариант 4**: "Пакет выгод" (объявительский стиль)

**Выбор детерминированный:** `hash(car_id) % 5` → один лот всегда одна озвучка, разные лоты → разные варианты.

---

### 2. Ударения в марках
**Было:** edge-tts читает марки без ударений неправильно (КИА вместо КИ́А).

**Решение:** Словарь `BRAND_PRONUNCIATION` в `config.py`:
```python
BRAND_PRONUNCIATION = {
    "Кia": "Ки́а",
    "Хёндай": "Хёнда́й",
    "Фольксваген": "Фольксва́ген",
    "Ауди": "А́уди",
    "Мерседес": "Мерседе́с",
    "Тойота": "То́йота",
    "Хонда": "Хонда́",
}
```

Функция `apply_brand_pronunciation()` применяет ударения к тексту **перед TTS-синтезом**.

## Логирование

В логах (app.log) теперь видно, какой вариант озвучки был использован:

```
tts_generator: текст подводки сгенерирован (вариант 2, 45 слов, ...)
```

Это помогает отследить, какой вариант промпта использовался для каждого лота.

## Как это работает (примеры)

### Пример 1: Один и тот же лот дважды
```
car_id = "encar_42123456"
hash("encar_42123456") % 5 = 1
→ Вариант 1 (энергичный) всегда
```

### Пример 2: Разные лоты
```
car_id = "encar_42123456" → Вариант 1 (энергичный)
car_id = "kbchachacha_28500000" → Вариант 4 (пакет выгод)
car_id = "charancha_55000" → Вариант 2 (вопрос)
```

### Пример 3: Ударения
```
"Киа Кей Три" → apply_brand_pronunciation() → "Ки́а Кей Три"
"Хёндай Соната" → apply_brand_pronunciation() → "Хёнда́й Соната"
```
