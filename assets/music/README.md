# Фоновая музыка для видео (video_generator.py)

Положи сюда несколько треков без авторских прав (`.mp3`/`.m4a`/`.wav`/`.ogg`) —
`video_generator.py` выбирает случайный трек из этой папки для каждого
ролика. Если папка пустая — видео собирается без звука (это не ошибка).

⚠️ Файлы нужно закоммитить в репозиторий (не добавлены в `.gitignore`
специально) — иначе на GitHub Actions (чистая виртуальная машина при
каждом прогоне) музыки просто не будет и видео там всегда будут без
звука, даже если локально треки есть.
